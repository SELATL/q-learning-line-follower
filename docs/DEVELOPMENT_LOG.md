# 개발 로그

## 이전 대화와 코드에서 확인된 과정 — 정확한 작업일 미확인

1. LEGO 선 추종 기억을 바탕으로 Python 2D에서 Q-learning을 공부하는 방향 선택.
2. 트랙·차동구동·좌우 센서·수동/규칙 제어·화면·테스트 작성. 최초 생성 이력·커밋은 확인 불가.
3. 이전 ZIP 검토에서 기존 테스트 9개 통과, 고정 조건 100초 규칙 주행 확인. 이 결과는 RL 학습 결과가 아니다.
4. Q 업데이트와 종료 시 미래 가치 제외를 숫자 예제로 학습.
5. 사용자가 IDE에서 env.py 작성. reset/step 연결 후 초기 센서 `[14.91503095,66.8248934]`, 직진 후 `[7.3180869,73.97068683]` 보고.
6. distance_error 작성 중 `self.robot.y` AttributeError 발생. `self.sim.robot.y`로 수정, 초기 오차 0·직진 후 약 0.0000277m 확인 보고.
7. heading_error 함수가 제안됐으나 사용자의 실행 확인은 없고 이번 코드에도 존재하지 않는다.

## 2026-11-03 — 이전 준비

- 실제 IDE 작업본을 읽어 이전용 사본을 작성. 기존 소스·의존성·테스트 내용 보존.
- 중복 프로젝트 폴더, Python 설치 패키지, 캐시는 복사하지 않음. 원본은 그대로 유지.
- AGENTS·맥락·아키텍처·결정·로드맵·검증·새 세션 프롬프트 문서 작성. 기존 README 내용을 유지하며 이전 안내 통합.
- 로컬 Git 및 연결된 GitHub 계정을 조회. 확인된 원본에는 Git 이력 없음. 연결된 앱에 보이는 저장소 목록에는 동일 프로젝트 없음. 이 조회가 계정 전체 저장소 접근을 보장하지는 않음.
- GitHub 생성·remote 변경·push는 실행 전 승인 대기. 결과는 VALIDATION.md와 README의 상태 표시 참조.

실패한 학습 실험이나 폐기한 구현이 있었다는 근거는 없다. 센서 전용 학습, PPO, MuJoCo, 노이즈 실험은 보류된 확장 주제다.

## 최초 업로드 승인 후 — 같은 이전 작업의 후속 단계

- 사용자가 Private 저장소 생성과 최초 커밋·remote 연결·push를 승인했다.
- GitHub 후보 주소 재조회는 404. 생성 도구와 로컬 gh가 없어 브라우저 생성 경로를 선택했다. 브라우저는 GitHub 로그인 화면으로 이동했으며 사용자 로그인을 기다린다.
- 최초 커밋 author는 확인된 GitHub 계정 SELATL과 GitHub noreply 주소를 사용해 개인 이메일 노출을 피한다. 시스템 전역 Git 설정은 변경하지 않는다.

- 최초 로컬 커밋 `240885a` 완료(21개 파일). staged 비밀·개인 경로 패턴 발견 없음. 원격은 로그인 완료 후 생성·연결·push 예정.
