## 우선순위와 의존관계

1. **P0 이전 마무리:** 사본·문서 검토 → 저장소 중복 확인 → 외부 작업 승인 → Private 생성/기존 remote 연결 → push → Mac/Cloud에서 clone 검증. Private 생성·remote 연결·최초 push 완료. Mac/Cloud clone 검증은 남음.
2. **P1 환경 설계:** heading_error 구현/직진 후 약 -0.529° 확인 → 상태 이산화/경계 검증 → 전진 거리·보상 정의 → 실패·시간 제한 → Gymnasium 어댑터와 check_env. 기존 Simulator API 보존.
3. **P2 학습:** 환경 검증 후 Q-learning. 경험 한 개의 수동 계산과 실제 업데이트 일치 확인. 평가 시 탐험 끄기, 학습/평가 조건·seed·버전 기록.
4. **P3 비교:** 규칙 제어와 동일 조건·여러 실행으로 이탈 없는 비율, 평균 중심 오차, 부호 있는 전진량 비교. 학습 곡선만으로 성공 주장 금지.
5. **P4 확장:** 센서 전용 상태·노이즈·새 트랙. PPO/MuJoCo는 선택 과제.

## 알려진 제약

- 기본 원·고정 출발점만 검증. 두 센서가 흰색인 관측의 모호성.
- 초기 센서가 모두 흰색이라는 구상과 실제 기본 센서값은 다름.
- 이탈 후 자동 복귀·충돌·실물 물리 없음.
- env.py 전용 자동 테스트 없음. 기존 9개 테스트는 env.py나 Q-learning을 검증하지 않음.
- Mac/Cloud GUI와 새 설치는 아직 미검증. 의존성 lockfile 없음.
