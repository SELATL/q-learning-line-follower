# 기술적 결정

## 대화에서 채택한 출발안 — 구현 예정

- Tabular Q-learning부터 시작. 신경망 없이 표와 업데이트를 직접 확인한다.
- 처음에는 거리·방향 오차 25개 상태와 3행동. 정확한 시뮬레이션 정보를 쓰므로 센서 전용 실물 정책과 동일하다고 주장하지 않는다. 구간화는 정보 손실이 있고 완전한 Markov 상태를 보장하지 않는다.
- Gymnasium 어댑터를 추가해 표준 인터페이스 사용. 학습 라이브러리가 아니라 환경 인터페이스라는 점을 설명한다. 의존성·spaces·seed·반환형은 구현 시 검증한다.
- 실패 종료는 미래 가치를 0으로, 단순 시간 제한은 계속되는 과제의 중단으로 처리해 bootstrap을 검토한다. 시간 제한을 진짜 목표 시간으로 정의할 경우 상태·목표 설계도 재검토한다.
- 보상 계수·실패 경계·1,000 step은 초기 실험안이다. 상태 경계·reward 변경 시 실험 조건·공통 평가 지표를 남긴다. 다른 reward의 총합만으로 우열을 판정하지 않는다.
